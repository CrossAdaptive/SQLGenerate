,,, Dependencies

~source/include/sqlgen.h~
#include "libbase.h"
#include "libbase/Object.private.h"
#include <ctype.h>
~

SQLGenerate uses several classes from libbase -- most notably String and Dictionary.
The 'ctype.h header is included to allow use of the 'tolower' function.

,,, Types

The 'Types' enumeration type is used to record the different SQLGen types.

~source/include/sqlgen.h~
typedef enum _Types
{
    Blob,
    Bool,
    Boolean,
    Char,
    Coordinate,
    Date,
    Datetime,
    Double,
    Float,
    Geo,
    Guid,
    Int,
    Integer,
    JSON,
    Longblob,
    Longtext,
    Mediumtext,
    Money,
    Text,
    Time,
    Timestamp,
    Year
}
Types;
~

,,, Constants

The 'Output' enumeration type is used to record the output format to use.

~source/include/sqlgen.h~
typedef enum _Output
{
    MYSQL,
    PSQL,
    TSQL,
    ORACLE
}
Output;
~
