.. Generated Replace Procedure

The generated Replace procedure is shown below.
You should note the following:

1)  The parameters of the procedure correspond to all of the fields of the table in that order.
2)  The 'Security' option determines the "SQL SECURITY" mode.
3)  A "READ_ONLY" error is thrown if the database is in read-only mode.
4)  The procedure immediately sets the 'LAST_INSERT_ID' to zero.
5)  The passed values are then inserted into the table if a duplicate row does not exist.
6)  If a duplicate row exists the "INSERT INTO ON DUPLICATE KEY UPDATE" syntax is used to update the row; and the assigment "EMPLOYEE_ID = LAST_INSERT_ID( EMPLOYEE_ID ) updates the 'LAST_INSERT_ID'.
8)  If the '\$EMPLOYEE_ID' variable is not set (for a new insert), it is retrieved from the 'LAST_INSERT_ID'.
9)  Finally, "DO LAST_INSERT_ID( \$EMPLOYEE_ID )" is called to set 'LAST_INSERT_ID'.
10) It should further be noted that the passed 'EMPLOYEE_ID' can be a non-value and an auto-incremeted value will be returned.

DELIMITER //
CREATE PROCEDURE spgen_employees_replace
(
    $ORG_ID                INT,
    $EMPLOYEE_ID           INT,
    $employee_first_name   TEXT,
    $employee_last_name    TEXT,
    $employee_type         TEXT
)
SQL SECURITY INVOKER
COMMENT 'Generated by spgen.org'
BEGIN

    IF @@read_only THEN

        SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = 'READ_ONLY';

    ELSE

        DO LAST_INSERT_ID( 0 );
        INSERT INTO employees
        ( ORG_ID, EMPLOYEE_ID, employee_first_name, employee_last_name, employee_type)
        VALUES
        ($ORG_ID,$EMPLOYEE_ID,$employee_first_name,$employee_last_name,$employee_type)
        ON DUPLICATE KEY UPDATE
            employee_first_name  = IFNULL( $employee_first_name, employee_first_name ),
            employee_last_name   = IFNULL( $employee_last_name,  employee_last_name  ),
            employee_type        = IFNULL( $employee_type,       employee_type       ),
            EMPLOYEE_ID          = LAST_INSERT_ID( EMPLOYEE_ID )
        ;

        IF NOT $EMPLOYEE_ID THEN
            SET $EMPLOYEE_ID = LAST_INSERT_ID();
        END IF;

        DO LAST_INSERT_ID( $EMPLOYEE_ID );

    END IF;

END
