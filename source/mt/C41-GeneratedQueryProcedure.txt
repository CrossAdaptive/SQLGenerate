The following page shows the query procedure that is generated.
You should note the following:

1)  The procedure takes a parameter for each field specified in the 'Filter' option as well as the standard parameters -- 'order', 'limit', and 'offset'.
2)  The first line of the procedure performs sanity checking of the passed 'limit' value.
3)  There is an 'IF/ELSE' code path for each 'OrderBy' option specified; and the default is the first one specified.
4)  Each parameter is optional -- if a non-value is passed ('' or 0) it will not affect the results set.
5)  If an 'order' is passed that is not specified in the 'OrderBy' option, an error will be thrown.
6)  The 'Security' option determines the "SQL SECURITY" mode.
